## A rigorous first experiment

Proposed question: does source-linked spatial memory improve retrieval and shared reference compared with ordinary photos/notes on the same task?

Use a small scene whose objects, changes and source images can be independently checked. Separate a test of manual object-indexed memory from a test of learned geometry so that a benefit cannot be attributed to the wrong component. Include useful positive questions as well as ambiguous identity, missing scale, occlusion, moved object, source correction and private/shared eligibility cases.

Before execution H06 fixes the task set, reference measurements, scene/session grouping, source rights, thresholds, attempt budget, allowed corrections and claim scope. Put related views/crops of the same scene in the same independence group where needed. Keep the evaluator's protected examples out of candidate optimization; report any exposure honestly. A UI study with two users is descriptive for those users, not a general population claim.

Measure answer correctness with exact evidence localization; object association/identity errors; time and correction awareness; metric error only where an independent scale/reference exists; failed relocalization and stale-state handling; unintended disclosure; task completion effort and distraction; latency, peak memory and total cost. A guessed precise answer is not better than an honest supported partial answer. A private-data leak cannot be offset by a higher mean usefulness score.

The future protocol should have stable attempt IDs and preserve negative/partial runs. This document deliberately does not invent passing thresholds after seeing results, redefine RI-01 denominators or claim any experiment already ran.

## Open questions worth preserving

Can learned geometry be corrected incrementally without losing object identity and source lineage? Can a useful memory preserve the exact event location without retaining unnecessary raw life recordings? How should uncertainty be conveyed haptically without teaching a false sense of precision? When does a shared reference save more effort than a simple message? Can an active-perception planner choose a materially better next view than a fixed/manual baseline? When does a generative rehearsal improve a decision rather than increase confidence in an unsupported scenario? Which generalizations survive a changed room, person, device, session or sensor mount?

These are research directions with measurable tests, not reasons to abandon the ambition and not claims of solved capability.
