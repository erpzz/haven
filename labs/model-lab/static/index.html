WHAT WE RECORD

Separate the different speeds.

First output: local send to first answer or reasoning text.

End-to-end tokens/s: backend-reported completion tokens divided by total request time.

Decode tokens/s: shown only when the engine reports it. Stream chunks are never counted as tokens.

Performance is not answer quality. Read the outputs too. A shorter wrong answer can win a speed test.

STRATA · LARGE-MODEL EXPERIMENT

Bring the big model home.

Strata v0.1.39 runs Qwen3.8-Flash-Next using GPU + RAM expert caching and speculative decoding. It is a separate inference engine—not a llama.cpp plug-in.

On your RTX 2070 Super

Upstream documents RTX 20 support, but warns that 8 GB is slow. Expect a roughly 70 GB model download plus preparation files and substantial RAM use. Start at 8K context, one request and images off. See the current PC qualification report for measured results.

  1. Run SETUP-STRATA.cmd in this folder.
  2. Review its disk/driver check and explicitly confirm the download.
  3. Run OPEN-STRATA.cmd, then connect below.

Attached servers remain under your control. Disconnecting or exiting this lab leaves Strata running. Use STOP-STRATA.cmd for a server opened by OPEN-STRATA.cmd.
