| ASTRA-M1 | Isolated simulator / telemetry | Separate accepted M0 evidence and operator assignment | Implied approval from the research hub |

Every package needs an explicit owner, allowed files, base version, acceptance cases, resources and stop condition. Importing a proposed package is not starting it. Dates/effort estimates in old documents are not remaining-time promises.
