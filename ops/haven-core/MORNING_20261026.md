The storage evidence ranks the USB link as the dominant cold-start constraint.
It does not prove an exact 10× gain after moving a cable. The next physical test
requires planned shutdown, a known SuperSpeed connection, verified negotiated
speed, then one timed cold start. Never unplug the running root filesystem.

The tool answer correctly identified the 480 Mbit/s root link, initialization
history and current memory availability. It incorrectly suggested retries as a
necessary discriminator of bandwidth limitation and proposed reusing effective
loader rate as a throughput measurement. Therefore cited evidence is useful,
but neither citation membership nor COMPLETED establishes a correct diagnosis.

## Independent peer contribution and disagreement

Claude's full matched 110-ID experiment: base 0.6B 14, teacher-SFT 38,
oracle-SFT 38, Strata 55, deployed 4B 76. Teacher and oracle used the same 232
training IDs / 139 steps but unequal target-token counts (21,457 vs 12,444).

Claude challenged Codex's worker credential transport: a replacement TCP
listener could receive the bearer after SSH disconnected. Codex replaced it
with SSH Unix sockets inside a private owner directory and tested that a dummy
TCP listener receives zero headers. Model digest provenance is now explicitly
WORKER_DECLARED on the control host. Claude also identified false-zero kernel
history on unreadable journals; the code now requires an observed kernel record.
Strata transition state is checked before fast-runtime startup.

## Operation, rollback, and next decision

Open with `python3 ops/haven-core/open-lab.py` from the current main checkout.
The launcher maintains the private SSH tunnel and opens the authenticated browser
without requiring copied keys. `http://127.0.0.1:8877/` is the local origin; a bare
URL alone is not a fresh authenticated session. Use the prepared runtime buttons
for Strata/4B, and the worker selector for Mac versus the current Slink runtime.

Before application rollback, verify no active jobs and whether the Lab owns an
engine or merely attaches to Strata. Preserve any external Strata process; an
application restart can reconnect to it without a cold start. Restore the prior
recorded deploy branch, restart only the Lab, then reconnect its previous backend.
`mac-worker.py disable` stops only the owned Mac worker/tunnel; retain weights,
keys and private receipts. Never uninstall shared Homebrew dependencies blindly.

**One next decision:** schedule the reversible powered-off SuperSpeed cable/port
test. It addresses the measured cold-start bottleneck before more loader tuning
or large-model experiments. Software follow-up should prioritize frontend/user
identity integration over another model training run.
