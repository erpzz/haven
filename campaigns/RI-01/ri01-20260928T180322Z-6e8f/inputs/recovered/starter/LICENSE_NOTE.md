# Ownership and third-party licenses

This starter does not impose a new open-source license on Eric's private project or redistribute external research/model weights. The owner should choose a repository license before public release. Public source links retain their authors' licenses. Model weights, software, voices, datasets, CAD designs and printer profiles can have different terms; check each exact artifact before distribution or commercial use.

Earlier user-provided project deliverables are preserved for continuity. Do not publish this repository by default: it contains project-specific plans and names, even though no real health samples, credentials or device telemetry are intentionally included. A public export requires privacy and license review.
