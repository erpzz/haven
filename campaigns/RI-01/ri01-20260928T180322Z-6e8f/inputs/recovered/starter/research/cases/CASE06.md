# CASE06 — Mobile manipulation learned from demonstration

**Primary evidence:** R07 in [source register](../SOURCES.md). **Maturity:** RESEARCH_DEMONSTRATIONS. **Owner:** H10.

Read the source entry for the exact verified finding and access limitations. The following is an original Haven adaptation proposal, not a claim that the cited researchers implemented Haven or that this package reproduced their work.

## What to learn

Human-mediated demonstration can be a bridge between teleoperation and a bounded learned skill.

## Smallest useful adaptation

Plan a light inert-object transfer on a supervised bench with held-out starting positions.

## How to evaluate

Success across variations, manual interventions, dropped/ambiguous outcomes.

Declare the baseline, input/fixture permissions, configuration identities, ground truth and independent review before testing. Retain failures and uncertain outcomes. No test is executed by this research card.

## Boundary

Do not copy hot/sharp demonstration tasks into an unqualified home robot.

## Promotion handback

Return exact artifact/environment versions; source/license/access findings; an apparatus/data list; measurable expected outcomes; risk/consent and stopping conditions; bounded time/spend; and the requirement/contract changes needed. A promising result becomes a separately approved work package, not an automatic new runtime tool.
