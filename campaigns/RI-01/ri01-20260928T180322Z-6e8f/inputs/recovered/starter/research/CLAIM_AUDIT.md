# Claims that must not silently carry forward

| Claim family | Correct treatment in this cumulative handoff |
|---|---|
| “We already built/accepted M0” | Only in-progress user report exists here; inspect actual evidence before asserting completion. |
| Historical sandbox runtime failure | Not evidence the PC is unsuitable; keep separate from actual Ubuntu setup. |
| Earlier model API prices and aliases | Archived as dated examples; no approved live rates or full monthly forecast. Refresh official tariffs before a paid benchmark. |
| Small model downloadable size | Not total runtime RAM/VRAM; evaluate context, media, concurrency and actual GPU. |
| Muse/Hermes confusion | Different product/framework categories; no assumed public Muse inference API from an announcement. |
| Hermes context overhead | Current guide must be checked against chosen release; do not pretend full framework uses a tiny standalone prompt. |
| General glasses support | Per-feature/per-SKU preview limits; exact production route unqualified. |
| Apple HealthKit authorization specifics | Prior requirement retained; this session's landing page yielded only a JS shell. R39 requires a substantive native-API reread before implementation. |
| WiFi “see through any wall” | Distinct presence, location, geometry and semantics; exact measurement access/geometry/environment matter. |
| Wiffract “reading” | Controlled object-edge/letter-shaped targets, not arbitrary text behind walls. |
| Thermal “through wall” | Do not use thermal observations as hidden geometry without a supported measurement model; this is not the RF research route. |
| A-Lab novelty/success headlines | R15 correction was read: revised novelty language and identification/success treatment. Use corrected evidence; no unqualified discovery counts. |
| AED delivery proves Haven saves lives | Field observational delivery evidence is not a Haven clinical outcome or randomized survival estimate. |
| A light/speaker on an enterprise drone fits a Mini | Exact payload/platform compatibility is still a gate. |
| LoRa/mesh provides internet | A local/relay network needs a real upstream for internet; truthful offline state required. |
| All through-wall RF is forbidden or all is permitted | R33 governs a particular UWB category; exact equipment authorization and operation need review, without a blanket WiFi conclusion. |
| 3D model/print completion proves engineering success | Need inspected physical dimensions/performance and exact configuration; second-model agreement is insufficient. |
| Current robotics model can control any body | Match observation/action interfaces, calibration, access and resources; restricted products remain leads. |
| Package validator passing proves product safety | It checks repository structure/fixtures only. It runs no M0, medical, aircraft, printer or sensing acceptance. |

The source register is dated and intentionally concise. Do not copy a long paper or vendor page into a handoff when a precise finding, link and limitation suffice. All new measurements must come from an actual reproducible test, not extrapolated marketing.
