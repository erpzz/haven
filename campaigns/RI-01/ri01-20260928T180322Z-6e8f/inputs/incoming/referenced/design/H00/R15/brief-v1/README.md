## Proposed organizing idea

A user moves from a global picture to a regional event, an authorized local observation, a sensing instrument, its fixture and the experiment behind it. They can ask what is known, rewind retained evidence, inspect uncertainty and compare an alternate scenario. The same interface can show sponsored research jobs and qualified resources without becoming the component that grants permissions or directly controls machines.

The three initial design priorities are the **world inspector**, **time machine** and **scenario fork**. The fog-of-war model, resource board and engineering lineage should connect them. These are priorities for investigation, not a frozen implementation order or proof the integrations work.

A useful implementation should beat using God’s Eye View and a separate event table side by side on a defined task. Start from one regional scene and a few meaningful interactions, not a compulsory installation of every open-source project mentioned in the assignment.
