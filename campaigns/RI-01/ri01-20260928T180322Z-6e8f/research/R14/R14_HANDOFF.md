## Top-five deep dives and useful progression

**1. Deliberate input (PROP-01).** The first target is selecting one of four harmless draft actions, not unrestricted handwriting or actuation. A button baseline establishes whether a task actually needs a new channel. Replay can reveal cross-session nuisance and abstention requirements; it cannot establish comfort or user benefit. Later authorized sEMG work must bind wearer's explicit session, placement revision, label protocol and held-out sessions. A simple classifier with an idle class is the first comparator. A language model must not fill uncertain intent. Positive value is fewer cumbersome interactions at equal or lower false activation and correction burden. End-to-end cost includes cleaning/consumables, fitting time, host energy and repeated calibration. Escalate only if replay shows incremental signal value and a complete acquisition/rights dossier fits the budget.

**2. Referent selection (PROP-02, with PROP-07).** A seated user selects a known region in a benign image, then confirms. The system should answer a source-supported question about that region and preserve the exact original/crop transform; “left one” resolves only against the current chosen image. Ordinary gaze at a private item is not consent to summarize or share it. A moving camera, new wearer or changed lighting invalidates affected calibration. Later richer scenes may combine selected speech and image evidence, but audio timing and gaze timing remain uncertain intervals; overlap cannot establish which came first. Thermal, RF and historical geometry stay separately labelled. Useful progression is explicit touch → supported OS gaze selection → source-linked multimodal question, with actual APIs and no metric geometry inferred from an uncalibrated image.

**3. Tactile evidence states (PROP-05).** Start with three user-learnable cues and a visible legend. Candidate meaning is “new private item,” “confirmation needed,” and “unavailable”; direction or urgency is not encoded until independently assessed. A haptic command accepted by an API is not observed physical vibration or successful human perception. Watch restrictions and interaction with heart-rate acquisition remain from R04. Screen-only and single-cue baselines determine whether more patterns are worth learning. Seated low-risk testing must record cue confusion, missed primary task and fatigue, not just recognition accuracy. Later spatial/RF information may drive evidence-state cues, but never “path is safe” from unknown geometry. A pleasant or novel cue without practical benefit is a negative result.

**4. Extra dexterity (PROP-08).** Choose one harmless tabletop task before choosing an embodiment. Compare no aid, a fixed clamp, and an unpowered wearable-form mock using the same object/layout. Task completion, placement accuracy, donning/removal, interference and effort all matter. No model or motor is needed to learn whether the form factor is worthwhile. R09's actual author specifically requires PHYSICAL_ACTUATION_UNSUPPORTED for this passive stage. Future powered work needs a separately sealed domain job, task/embodiment qualification and device-local stop/recovery; torque-off may drop a load. Removing a wearable UI does not prove that a remote actuator stopped. A powered extra finger is a separate specialist gate, not the automatic next step after a comfortable mock.

**5. Cognitive offloading (PROP-10).** Two synthetic users keep distinct private notes and a deliberately shared project. One note is corrected, one reminder cancelled, one delivery delayed. The positive target is retrieving the current decision with its source and an understandable receipt, not merely declining every request. Compare deterministic retrieval and an ordinary notebook workflow before model inference. A wrong but confident recalled intention is worse than an honest missing source; nevertheless abstention cannot count as task success on answerable cases. Broader augmentation can route a deliberate gesture to this existing daily capability, keeping the novel input replaceable. This yields useful progress even if biosignal work proves too expensive.

## Three unusual combinations, explicitly unproven

1. **An uncertainty sense for spatial evidence:** haptic cue + R07 temporal/provenance ledger + MM-VISION selected region. The new contribution is a learned distinction between available, contradictory and absent evidence, not a new biological sense. Prior art in haptic substitution prevents a novelty claim. Falsify with E03/E04 if text is equally effective or cues produce unwarranted certainty.
2. **A tactile memory of a failed engineering trial:** authorized fixture-test evidence + synchronized contact-event replay + source-linked project memory. A designer can inspect why a candidate failed without reenacting contact. The key hypothesis is improved diagnosis over video/text, with correlated evidence and unknown forces preserved. This is not remote force reproduction, simulation validation or robot qualification.
3. **A removable garment cue for resilient communication:** module identity/garment revision + deliberate input + separate relay/application/presentation receipts. A wearer could learn that a draft is queued versus shown locally without assuming another person received it. Disconnection and reattachment must not restore old authority. Compare a pocket phone first; textiles only earn their complexity if the complete maintenance burden falls.

## Dissent, red team and sequencing

The scientific ambition is retained, but the likely near-term winner may be an ordinary control combined with good memory and evidence handling. A new channel is not automatically more accessible: an extra foot control can exclude people, gaze can fatigue, haptics can distract, and a wearable can interfere with existing assistance.
