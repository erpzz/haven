## Disagreements and source corrections that change the plan

S01 demonstrates useful input yet ordinary interfaces can be faster: novelty is not an endpoint. S02/S03's current artifact edition differs from the paper's earlier release; neither establishes checkpoint commercial rights. S08's broad first-exposure sample strengthens accessibility research but does not replace a longitudinal comparison with a clamp or second hand. S06's hearing population is not a deaf-user deployment study. S07 uses fMRI, whereas S15 is invasive; neither supports a low-cost EEG “read any thought” claim. S11's electronic subsystem power is not total battery life. S17's dependency notice prevents a blanket license shortcut. S09's moving documentation and unknown owned tuples prevent a compatibility promise.

All source performance numbers remain source-reported. No new study, source replication, user benefit, model throughput, price quote, calibration or hardware operation was measured by this assignment. Later rights review must distinguish paper text, code, weights, participant data, fabrication files, SDK, patents/terms and generated-output permissions. The absence of a located correction in this finite pass is not proof that none exists.
