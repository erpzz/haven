# Proposed cross-modal evaluation

All cases NOT_EXECUTED. This is a new MM-FUSION composition protocol, not a replication or pooled extension of R07, R08, MM-VISION, MM-AV or R14. It tests whether synthetic typed evidence is composed faithfully; it cannot establish real perception or native delivery. Actual model studies keep their independent frozen protocols below.

## E-MF-01 — Inert useful composition replay

Two proposed routes: B, a deterministic source-by-source evidence table with explicit eligibility; C, a deterministic typed FusionSet plus grounded answer/proposal table. No model, decoder, native endpoint or executor. H06 authors and controls immutable fixtures/oracles, while H08 implements composition after authorization. Original synthetic asset identity, values, source family, rights/authority state and exact expected claims/records are fixed before runs. No self-written model answer is the truth label.

Thirty-six families below; one run per family per route = **72 attempts inclusive**. Freeze18 development and18 protected families, each four positive and14 negative/uncertain. Concrete instances/permutations and protected expected records stay unavailable to implementer until run; public case descriptions are not secret. No fitting/training; development executions consume their36 slots. Each failure, partial, cancel, retry or tuning run consumes a slot, replacing planned coverage. Missing required case/route coverage is INCOMPLETE/INCONCLUSIVE, never a smaller passing denominator. No planned repeat or hidden spare allocation.

Each fixture's evidence archive contains original synthetic record/asset manifest, native profile and transform/calibration/clock refs, complete authority snapshot/mutations, expected normalized claim/state, actual output/reasons and attempt/cost ledger. Where pixels/audio would matter, mock values remain explicitly SYNTHETIC_ORACLE_INPUT; no actual image/audio model score is claimed. Each row names its modality owner; H06 independently owns every expected-result adjudication.

Protected decision rule for each route: all four useful positive families correct, all14 protected negative/uncertain families correctly bounded, zero privacy/authority/physical escapes or measured-evidence fabrication. All36 per-route outcomes are reported; required development/protected coverage remains72 total. C is not declared superior merely for more elaborate output: compare source-inspection steps, supported-answer completeness and confusion/error against B using independently fixed rubric. Human usability and native latency remain untested. A deny-everything strategy fails positives. This small suite supplies no statistical population safety/accuracy bound.

Proposed run ceiling: one local process,10 minutes,256MiB fixture bytes,50MiB new result records,$0 paid calls, no device/network/model routes. Implementation/review ceilings are in NEXT_PACKAGES.md. H06 also prepares isolated evaluator mutation checks for four dangerous shortcuts (ACK->perceived, crop->independent, receipt->capture, scene->permit). Run exactly one targeted case per faulty C variant: four separately labelled software verification invocations, no repeats. The total proposed package ceiling is therefore 72 comparison attempts plus four mutation checks = 76 invocations. Freeze their identities before execution; a failed/partial retry consumes the same allocation and missing required coverage is inconclusive. They cannot add model attempts to any pilot. Fail a targeted mutation before promoting the evaluator. A flawed oracle is versioned and affected results invalidated, not quietly edited to pass.

## Upstream protocols remain distinct

- MM-VISION MV-P1: two routes,24 groups,48 attempts inclusive; exact split/positive denominators and any threshold change must freeze together under MV-G3/G4. Retries require a pre-results allocation change, not discarded failure. No third route. Rights, lifecycle/decoder, semantic oracle and metric/native gates remain.
- MM-AV original plus **ADDENDUM-1**: ASR-only faster-whisper1.2.1 small/int8 CPU versus medium/int8 CPU, beam5, same preprocessing.24 independent source families:12 development and12 held-out; each split six answerable/six negative or uncertain.24x2=48 inclusive attempts, zero planned repeats. Per route held-out >=5/6 useful positives and6/6 negatives, critical tokens correct or unresolved, zero escapes. Failed/partial/tuning/retry work replaces slots; missing coverage is inconclusive. No video/omni/TTS allocations. This materially supersedes former10/12 criterion, not equivalent evidence volume.
- R07 E07-B differs from R06 E0; no pooling or silent protocol substitution. R08 E01 needs its frozen estimand, independent metrology and uncertainty/interval method before its physical study. Scalar evidence does not qualify full spatial fusion.
- R14 E07:24 person/session families x4 routes=96 inclusive proposed attempts. Exact checkpoint train/validation exposure and person-plus-session grouping must be verified; twelve held-out families are not twelve new people. Eligible idle/nuisance data and distinct sessions must actually exist. Stop/redesign before freeze if not. No human acquisition, generalized mind-reading or clinical evidence is supplied by MM-FUSION.
