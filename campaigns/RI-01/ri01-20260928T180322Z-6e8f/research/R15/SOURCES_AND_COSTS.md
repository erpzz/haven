Dates, quotas and rights are source-backed research findings, not contractual service availability. 429/quota, timeout/outage, stale, missing coverage, withdrawn/corrected and unsupported schema remain distinct. Unknown quota never means unlimited. First adapter caps are conservative product design limits: one manual request, maximum2MiB response,20seconds total, no auto-poll, at most one later operator-requested retry after provider guidance. Exceeding a limit rejects with an honest partial/unavailable state. URI redirects are explicitly allowed only where the provider's exact route is reviewed; generic redirects are denied. No production feed was fetched to validate these choices.

## Three cost profiles

**P0 — no paid service and no billing credentials.** Existing host; original fixtures, optional manually requested D01/D02 when separately authorized, untextured/schematic map, deterministic answer and source table. Account-free source route is distinct from D03 free-key and D04 free-account routes. No credentials, cloud model, ion/Google imagery, hosted collaboration or public storage are prerequisites. Software incremental license fee is0 under eligible terms; total cost is UNKNOWN until storage, power and operator effort are measured. Proposed ceiling:200MiB prototype fixture storage,2GiB frontend memory target,60minute session, zero paid API calls; byte/energy limits are not measurements. Development estimate24–40engineering hours plus8review/test hours, original planning estimate with ±50% uncertainty, not a market quote.

**P1 — optional low recurring cost, capped by admission rather than alerts.** Same local architecture; optional private object storage for approved public bundles only. Cloudflare R2 Standard documentation lists USD0.015/GB-month,4.50/million ClassA and0.36/million ClassB; free allocation10GB-month/1millionA/10millionB, rounded billing units and free direct egress. At20GB-month,100,000A and1millionB, estimate USD0.15/month if the entire free allowance is available; conservative calculation without free allocation is USD5.16. Taxes, another service/worker/domain, existing account consumption and minimum billing effects are excluded/UNKNOWN. This is a workload example, not a guaranteed bill. [Pricing, updated2026-08-07](https://developers.cloudflare.com/r2/pricing/).

Proposed operator ceiling USD6/month applies only after verifying dedicated accounting, all possible billable routes, storage and request admission under I05. Keep bucket private, no public unbounded read URL, enforce exact remaining request/byte/monthly exposure at the only qualified client and retain unknown admitted spend. Public release, provider credentials and server exposure are not authorized here. If any bypass or unbounded externally triggered billing remains, this profile is INELIGIBLE and stays P0. An alert, shutdown after the fact or a revoked app token is not a spending guarantee. Optional inference remains0calls in this profile; a future provider/model needs a separate exact rate/retention/containment review.

**P2 — advanced optional lab.** Add one task-justified tool at a time: QGIS/GDAL/PySTAC for imagery preparation; MCAP/Rerun for rich recorded streams; SUMO only for a measured traffic question. Hardware/model budgets are not quoted because no complete suitable configuration was selected. Inventory host RAM/GPU/storage/energy, backup copies, sensor/calibration/fixture costs, batteries/transport, software dependencies, training and maintenance before purchase. R08/R09/R10 retain metrology, embodiment, firmware, independent stop and full-system-cost gates. Local/open code does not make weights/data/compute or physical operation free.

At all profiles record input/output bytes, peak memory, session wall time, network requests, provider rate revision, reserved/confirmed/unknown spend and human minutes per correct task. Proposed human/compute budgets cannot override the existing runtime limits. No purchase or subscription recommendation follows from the cost example.
