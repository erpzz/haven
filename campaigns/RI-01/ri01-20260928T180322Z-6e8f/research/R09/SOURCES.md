## Rights and resource freeze before any model/SDK package

Record exact repository commit and submodules; dependency/codec license texts; selected checkpoint digest, architecture, tokenizer, processor, quantization/runtime; every base model license and use restriction; dataset edition/license, consent and permitted training/evaluation/publication; firmware/SDK API/auth/offline terms; asset CAD/texture/environment licenses; distribution notices and public-release permission. UNKNOWN disqualifies that artifact from adoption, not the unrelated no-model mock. Open-source code availability, paper claims and an accessible model card do not close all of these fields.

For a later model comparison measure actual host device/OS/runtime, peak RAM/VRAM, load/first-action/steady-state latency, worst-case interruption handling, bytes/energy and total attempts against an explicitly authorized budget. The present task makes no CPU/GPU fit claim. Prices, availability and branch contents must be refreshed at procurement/adoption; no broad web catalogue replaces the task-qualified decision.
