## Useful first path

A person selects a synthetic or licensed original image, types a question, and supplies currently authorized notes. Haven resolves the intended image/region, gathers a bounded evidence packet, asks the pinned local model in a separately authorized evaluation, validates citations and uncertainty, and releases a useful answer to the exact current private destination. Follow-up references point to the selected instance and source revision. Missing scale or contradictory evidence yields a bounded answer or request for an authorized measurement. The path must demonstrate useful positive answers as well as abstention; exact quotation alone is not semantic grounding. It does not depend on completing a global world model or physical fleet.

Keep Python 3.12, FastAPI, Pydantic 2, Jinja2, Uvicorn 1 and SQLite foundations and the M4 advisory `qwen2.5vl:3b` pin. These are compatibility constraints, not newly executed runtime qualification. In-process modules with explicit boundaries suffice initially. No broker, vector database, new agent framework, service split, active M0 route or database migration is proposed here.

## Five retained journeys

1. Daily decision recall: distinguish quoted history, present inference and a corrected memory; retain two-person shared/private boundaries and offline limitations.
2. Image-grounded follow-up: selected original and typed question plus current authorized notes, region citations, referent resolution, useful answer and abstention cases.
3. Multisensor incident replay: retain raw references, audio/video alignment, spatial/RF uncertainty, missing intervals and correlated evidence; replay is not current observation or action authority.
4. Permitted public regional Observatory question: use provenance, licensing/freshness, public-source uncertainty and bounded ingestion; public visibility alone is not unrestricted reuse permission.
5. Engineering learns from a failed candidate: preserve negative results and exact units/material/process/test conditions, separate proxy scores from protected evaluation and physical metrology, and require explicit requalification after material or configuration changes.
